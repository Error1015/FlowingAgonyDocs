# Quick reference

When you only need to confirm "can this item take that enchantment?" or "do these two clash?", this table is the fastest route. Click any name to jump to its full effect write-up in the index.

::: tip Reading the table
An em dash (`—`) in the *Incompatible with* column means the enchantment has no exclusions. Entries marked *Vanilla* are original Minecraft enchantments; entries marked *Other* come from the original mod but were not carried over to the remake.
:::
